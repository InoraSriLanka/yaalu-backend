# Yaalu Backend — Summary

## Overview
`yaalu-backend` is a [NestJS](https://nestjs.com/) (v11) backend service for the Yalu App. The repository is currently a freshly scaffolded Nest CLI project — it contains only the default boilerplate generated by `nest new`, with no custom business logic, database integration, or API endpoints added yet.

## Tech Stack
- **Framework:** NestJS 11 (`@nestjs/common`, `@nestjs/core`, `@nestjs/platform-express`)

- **Testing:** Jest (unit) + Supertest (e2e)
